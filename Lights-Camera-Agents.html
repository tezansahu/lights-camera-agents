Single agent vs. crew

One actor can play every role. Should they?

Why hire a crew
  • Specialists stay in character
  • Shorter, sharper briefs
  • Parallel takes, faster shoot
  • Debug & evaluate one role at a time
What it costs
  • More LLM calls → more latency & ₹
  • Hand-offs drop context
  • Harder to trace who broke what
  • Agents can argue in circles

Don't hire a crew to shoot a selfie.

From kit to code · Microsoft Agent Framework

One agent, a dozen lines.

from agent_framework import Agent
from agent_framework.openai import OpenAIChatCompletionClient

client = OpenAIChatCompletionClient(                     # 🎭 the talent
    model="gemini-3.5-flash-lite", api_key=GEMINI_API_KEY,
    base_url="https://generativelanguage.googleapis.com/v1beta/openai/")

reader = Agent(client=client, name="Reader",
    instructions="Extract the 5 key ideas from a blog post.",  # 📜 the brief
